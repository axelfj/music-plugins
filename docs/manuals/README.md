# Manuales / Manuals

Un manual por plugin, en español y en inglés: qué hace, cómo empezar en un minuto, qué hace cada control (con su rango y su valor inicial), recetas para casos típicos y tips. Si es tu primera vez, empieza por **[Primeros pasos](primeros-pasos.md)**: cómo instalar, cargar un plugin en FL Studio o Ableton, usar el sidechain y mandar MIDI.

*One manual per plugin, in Spanish and English: what it does, how to start in one minute, what every control does (with its range and default), recipes for common jobs and tips. If it's your first time, start with **[Getting started](primeros-pasos.md)**: installing, loading a plugin in FL Studio or Ableton, using sidechain and routing MIDI.*

## Una cadena típica / A typical chain

**Voz / Vocal:** Tune-R → EQ-R → Compressor-R → De-Esser-R → Delay-R y Reverb-R en envíos / on sends.

**Master:** EQ-R → Compressor-R (Glue) → Saturator-R → Stereo-R → Clipper-R → Limiter-R → Meter-R.

Los rangos y valores iniciales de estos manuales salen del código de cada plugin. Si cambias un parámetro en el código, actualiza su manual. *The ranges and defaults in these manuals come from each plugin's code. If you change a parameter in the code, update its manual.*
